# CosmoShop EAN preflight

Источник: локальный полный DE-снимок `var/import/samples/2/cosmoshop-de-products-full.jsonl`.

Этот этап не обращается к OKB и не решает, является ли строка вариантом, Sofort-товаром или ошибкой. Он только фиксирует фактическое состояние идентификаторов CosmoShop до сопоставления с OKB.

## Файлы

- `cosmoshop-ean-summary.json` — сводные количества и критерии проверки.
- `cosmoshop-ean-issues.csv` — только строки с пустым/некорректным/повторяющимся EAN либо маркером `Sofort` в имени или product number.
- `cosmoshop-ean-duplicates.csv` — одна строка на повторяющийся EAN с источниками и product number.
- `cosmoshop-ean-duplicate-audit.csv` — каждая исходная строка из повторяющегося EAN с технической классификацией группы.
- `cosmoshop-ean-duplicate-audit-summary.json` — итог классификации повторов.

## Важные правила

- Повтор EAN не является автоматической ошибкой и не означает автоматически вариант. Окончательное решение даёт OKB: для одного EAN нужно получить `productReference` и набор `productVariations` из `GET /extermal/get_products`.
- `Sofort` в названии или product number — только маркер для аудита, а не правило исключения из импорта.
- Чистым кандидатом для следующего этапа считается строка с EAN из 13 цифр, начинающимся с `4`, и без повтора в CosmoShop. Совпадение с OKB ещё должно быть проверено отдельно.

## Результат аудита повторов

Из 2 619 групп повторяющихся валидных EAN:

- 1 группа — точная копия source-строки;
- 2 515 групп — одна запись использует сам EAN как `product_number`, а другая запись делит с ней EAN;
- 54 группы — Sofort/legacy-маркер без записи с `product_number = EAN`;
- 49 групп — разные карточки с разными именами и product number под одним EAN.

До отдельного правила выбора источника **все 2 619 групп блокируют автоматический импорт**: из двух и более карточек CosmoShop нельзя молча создать один товар или вариант. Единственная точная копия — кандидат на ручное удаление/исключение одной source-строки, но это тоже не выполняется автоматически данным аудитом.

## Следующий этап

Сверить EAN с OKB и записать для каждой исходной строки: найден ли товар, его `productReference`, категория-имя и набор `productVariations`. По этой таблице определяются parent/variants и исключения.
